# Commercial Support

If your team is adopting imagor or running it in production and needs help with architecture, custom imagor components, multi-tenant setups, migration, or performance tuning, commercial support and consulting are available.

Typical engagements include:

- system architecture and deployment design
- custom imagor components such as processors, loaders, or storage backends
- multi-tenant deployments with tenant-aware configuration, routing, and isolation
- integrations with storage, CDN, auth, or internal services
- migration planning and rollout support
- performance tuning and production hardening

For bugs and feature requests, please continue to use GitHub issues.

For consulting inquiries, contact imagor@cshum.com.
